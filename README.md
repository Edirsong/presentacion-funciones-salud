# Funciones que laten, crecen y se eliminan

Presentación web interactiva: funciones trigonométricas y exponenciales aplicadas a ciencias de la salud (14 láminas y un reto extra).
Los modelos son didácticos; no sirven para decisiones clínicas ni para dosificar pacientes.

**Ver en línea:** https://edirsong.github.io/presentacion-funciones-salud/

## Uso
- `→` / clic: avanzar · `←`: volver
- `F5` o `F`: pantalla completa · `H`: ocultar ayuda
- Sin internet se usa Arial en lugar de la fuente Archivo.
